管理画面の使い方

売上・未回収・今日の対応を確認し、回収と顧客対応へ進む。

管理画面を開く →
メニューを押すと専用ページへ移動します。

顧客・案件・売上の保存データはページ間で共通です。ブラウザの「戻る」やブックマークも使えます。

毎日の流れ

ダッシュボードの今日対応する人・期限超過・未回収額・今月の見込利益を確認 → 回収管理から入金を記録 → 今日の顧客対応 → 必要時にバックアップ。

売上回収顧客・案件書類・契約入金照合資金繰り期限・引継ぎ集客通知保存・復元

最初の画面で経営状況を確認

売上・回収ダッシュボード

  • 今日対応する人・回収期限超過・未回収額・今月の見込利益を大きな4枚のカードで確認。カードを押すと対象一覧へ移動します。
  • 説明・その他の数字・前月比・グラフは基本閉じた状態。見出しを押すと開きます。
  • 「日・週・月のグラフを見る」で従来の期間切替。「売上分析」で今年累計・見込利益ランキング・担当者別・流入経路別を見る。

前月は同日までの比較。前月0なら比較不可。新規＝期間中に初買取、リピート＝期間前にも買取実績がある顧客。見込利益は未回収分も含みます。

回収を優先して対応する

回収管理

  • 「期限超過」「本日期限」「7日以内」「全未回収」で絞り込み。
  • 顧客名・残高・期限超過日数・担当者を確認。
  • 案件を押し、入金日・金額を入力。保存時の確認画面で顧客・金額・保存後の未回収額を確認して確定します。部分入金も反映されます。キャンセルしても入力は残ります。

誤入力は編集・取消・復元で訂正。CSV照合の入金は入金照合ページで取消してから照合し直します。今日が期日の案件は、まだ延滞には数えません。

顧客と案件を管理する

顧客一覧 ／ 案件管理

  • 「期限超過」「今日対応」「未回収あり」で1タップ絞り込み。検索・担当者・対応状況との組み合わせもできます。「条件をすべて解除」で戻せます。期限超過には対応日超過と回収期限超過を含み、今日対応は次回対応日が今日の顧客です。
  • 並び替えは「次回対応日」「未回収額」「見込利益」「最終更新日」から選択。金額は多い順、更新日は新しい順です。最終更新は顧客・案件・取引・通知の記録も含みます。
  • 顧客一覧は「対応日超過 → 今日 → 今後の予定 → 未設定 → 完了」の順で自動表示。対応日超過・回収期限超過を赤い表示で区別します。
  • 一覧やトップの「連絡した」で連絡日・メモを保存。「次回対応日変更」で日付と内容を変更できます。連絡記録だけでは予定を消しません。
  • 「入金記録」で未回収案件へ直接入力。複数案件がある顧客は対象を選びます。新しい案件の作成・金額の変更は行いません。
  • 顧客詳細の上部に累計取引回数（買取）・累計買取額・累計見込利益・未回収額を表示。その他の集計は開閉式です。
  • 「対応メモ」で記入し「メモを保存」。他の編集途中の項目は保存せず、日時付きで履歴へ追記します。新しい順に表示し、「メモのみ」「以前の履歴」でも確認できます。過去のメモは残ります。
  • ランク・流入経路・最終連絡日・次回対応は入力して保存。連絡日は実際に連絡した日を記録。
  • 新しい申込や審査・買取実績は「案件管理」で登録。

ランクは担当者が設定する管理ラベルで、自動審査には使いません。延滞経験は期日までに完済できなかった案件数（完済後も含む）。旧手入力売上は別台帳に保持します。

入力ミスと保存結果を確認する

入力漏れ・金額の上限超過・小数は赤枠と項目の下の説明で案内します。修正してから保存してください。保存できた場合は「保存しました」などの完了表示が出ます。入金登録・訂正、審査や買取の重要な変更、取消・削除・復元は確認後に反映します。よく使う連絡記録は一覧から開いて保存の2操作。入金などの重要操作には確認が1回加わります。

顧客をすぐに探す

顧客一覧の検索欄に、名前・電話番号・LINE名を入力します。全角／半角と電話番号のハイフン違いを吸収します。電話番号・LINE名は顧客詳細から登録・変更できます。

ログインとデータ共有について

GitHub Pagesは引き続きブラウザ保存デモです。現在はGitHub Pages版の改善を継続し、サーバー接続は進めていません。ブラウザや端末間の自動共有はありません。専用サーバー版のコード・手順は別途保管しています。

共有サーバー版の使い方

書類・契約・先払い予定を記録する

設定・業務ツール →「書類・契約」→ 案件

  • 「書類項目を追加」で書類名・状態・提出期限を設定。
  • PDF・PNG・JPEGを添付し、下の保存ボタンで確定。
  • 契約状態・確認期限・署名完了日を記録。確認用メモも出力できます。
  • 承認・買取前の案件は、先払い予定日・金額を入力すると資金繰りに反映。

添付は1つ500KB以下・合計約2MB。このブラウザ内のみ。自動OCR・電子署名ではありません。契約確認メモは契約書そのものではありません。

練習用の架空請求書PDFをダウンロード

CSVの入金を照合する

設定・業務ツール →「入金照合」

  • CSV見本をダウンロードし、UTF-8のCSVを選択。
  • 新規・重複件数を確認して取り込み。
  • 各明細で対象案件を選び、「確認して入金へ反映」。

列名は「明細ID・入金日・入金額・振込名義」。同じ明細IDは二重登録しません。候補は日付と金額によるものなので、相手と案件も確認してください。誤照合は「照合を取消」してやり直します。銀行への振込・接続は行いません。

今後の資金を試算する

設定・業務ツール →「資金繰り予定」

  • 現在の口座残高と、回収を何％と仮定するかを入力。
  • 本日から31日分の予定残高を確認。その他の支出予定も追加できます。

既に実行した入出金を含む現在残高を入力してください。翌日には残高を再設定します。期限超過の未回収や、日付未設定の先払いは予定額に含めません。回収を保証する予測ではありません。

期限・対応漏れと引継ぎを確認する

設定・業務ツール →「期限・対応漏れ」「AI・引継ぎ」

  • 今日までの書類・契約・顧客対応・回収・タスクを確認。
  • 引継ぎには、一意な受付ID・内容・担当・期限を入力。
  • 対応したら結果を記録して完了。「失敗例を追加」は架空の練習用です。

期限は画面内で表示します。AIの実監視・自動再実行・外部通知は未接続です。引継ぎの完了は、AI処理の成功を示すものではありません。

広告 → 送客 → 顧客 → 案件 → 利益

広告 → 分析／広告入力／送客・顧客／LP・媒体管理／データ移行

  1. 「LP・媒体管理」で名前を登録します。
  2. 「広告入力」で日付、LP・媒体・経路、広告費・表示・クリックを入力。成果・売上・利益は案件から自動計算します。
  3. 「送客・顧客」で送客を記録し、既存顧客へ紐付けるか新しい顧客として登録。新規顧客には流入情報が引き継がれます。再送客は初回流入を置き換えず追加できます。
  4. 顧客から「案件を登録」へ進み、買取済になれば成果・手数料見込・利益へ自動反映。別の再送客が成果につながった場合は案件の「広告・送客の紐付け」を選びます。
  5. 分析で期間・LP・媒体・経路を絞り、ランキング、前日・前月比較、単価、日・月推移を確認。赤字は赤色と文字で表示します。

利益＝請求書額面−買取額−案件直接費用−広告費−広告のその他費用（未回収を含む見込）。回収元本・旧売上台帳とは合算しません。ダッシュボード・売上分析の案件利益と、広告費控除後利益は別ラベルで確認できます。

以前のAd Noteの取り込み

Ad Noteを使っていた同じブラウザで「広告 → データ移行 → このブラウザのAd Noteを確認 → 取り込む」。見つからない場合は元のAd Noteで保存したJSONを選びます。元データは消しません。旧手入力の売上・成果・利益は参照用の原本として保存し、案件と二重に足しません。

過去の送客総数は同じ日付・LP・媒体・経路の名簿へ加算しません。総数と名簿人数の大きい方を採用し、未紐付け人数を表示します。通常の送客数は名簿から自動計算。旧CRMの広告費累計は日付不明のため参照として残し、日別の広告費へ自動加算しません。

保存・バックアップは広告・送客・顧客・案件をまとめたJSONです。旧CRMバックアップも復元できますが、復元は全置換なので広告を含む現在のバックアップを先に保存してください。端末間同期・広告API・LINEの自動取得はありません。

自己破産・任意整理の通知を記録する

「通知・責任者確認」→「通知を記録」

受領日・種別・通知元・記録担当者を保存。同じ顧客の人数は重複させずに集計します。訂正・理由付きの取消／復元ができます。

通知だけで永久自動否決にはしません。新しい審査判断は確認者・理由・確認チェックを記録します。実運用の責任者認証は未接続です。

データを保存・復元する

設定・業務ツール →「保存・バックアップ」

  • 「バックアップを保存」で、添付を含む全データをJSONファイルに保存。
  • 復元はJSONを選び、表示件数を確認して実行。現在の全データを置き換えます。
  • 閲覧だけにしたいときは「書込ロック」。誰でも解除できる誤操作防止機能です。

本番の担当者権限やログインではありません。ブラウザのデータ削除前・大きな変更前に、バックアップを手元へ保存してください。

現在は架空データ専用のデモです。

AI・LINE・銀行・電子署名・ログイン権限・共有DBには未接続。実際の顧客情報や通知書を入力・添付しないでください。
